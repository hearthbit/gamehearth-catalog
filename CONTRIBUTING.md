# Contributing

This catalog lists only the games of the Gamehearth project; every server that adds it trusts its games, so it does not take games from others for now. For your own games, create your own catalog (see the [starter repo](https://github.com/hearthbit/gamehearth-starter#putting-it-on-a-server)).

Bug reports about the catalog itself are welcome as issues. Questions about the platform, the SDK or the dev tool belong in the [platform repo](https://github.com/hearthbit/gamehearth/issues).
